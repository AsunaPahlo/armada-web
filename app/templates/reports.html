Basic Syntax

Queries follow this structure:

FIND <entity> WHERE <conditions> ORDER BY <field> LIMIT <n>

WHERE, ORDER BY, and LIMIT are optional.

Entities
fcsFree Companies — gil, supplies, sub counts
subsSubmarines — level, build, route, status
voyagesVoyage history — departure, return, duration
lootLoot records — items, value, route
activityActivity log — build changes, level ups, etc.
Operators
Comparison= != > < >= <=
TextCONTAINS NOT CONTAINS STARTS WITH ENDS WITH
SetsIN NOT IN BETWEEN
NullIS EMPTY IS NOT EMPTY

Combine with AND / OR. Use parentheses for grouping.

Quantifiers (for child fields)

When filtering a parent entity by its children (e.g., FCs by their subs):

ALLEvery child must match
ANYAt least one child matches
NONo children match
Advanced: COUNT & Expressions

Count matching children or set items:

COUNT(subs WHERE level >= 100)
COUNT(tags, "Mining")

Use arithmetic (+ - * /) in WHERE and ORDER BY clauses.
