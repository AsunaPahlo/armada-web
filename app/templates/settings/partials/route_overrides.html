About Route Overrides

Routes in the database are automatically classified as farming. Use overrides to mark additional routes as farming so submarines on those routes are not counted as leveling.

Optionally set an estimated Gil/Sub/Day value for each override. This will be used in dashboard gil calculations. Leave blank if unknown.
