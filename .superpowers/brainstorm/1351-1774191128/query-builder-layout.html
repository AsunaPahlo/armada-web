Query Builder Layout

How should the visual builder and text mode relate to each other?

A

Tabbed Mode Switch

Two tabs at the top: "Visual" and "Query". Switching to Query tab shows the generated text query that you can edit directly. Changes sync both ways — edit the text and the visual builder updates, or use the builder and the text updates.

B

Live Preview Below

Visual builder on top, with a collapsible query text preview always visible below it. As you click dropdowns, the query text updates in real-time. You can expand the text area to edit directly.

FIND FCs ▾ WHERE
all subs level ▾ > ▾ 111
▸ Query: FIND fcs WHERE all_subs.level > 111
C

Smart Text Input with Autocomplete

Primary interface is a text input with rich autocomplete, syntax highlighting, and inline suggestions. A small helper panel on the side shows available fields and operators. More like a search bar than a form builder.
